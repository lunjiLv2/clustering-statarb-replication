# Manuscript sources

Snapshot of the manuscript sources (sections/, figures/, bibliography). Since 2026-11-10 this folder tracks
the SSRN version 2 build: plain `article` class, `main.tex` + `preamble.tex`, built with
`pdflatex main; bibtex main; pdflatex main; pdflatex main`. The JFEC submission snapshot (OUP class) is the
last commit before that change, 7b3a7f2; its class and style files are still here, unused by `main.tex`.
`make paper-sync` copies sections, bibliography, preamble and figure PDFs from `CSA_MANUSCRIPT_SRC`, default
`../SSRNv2`. The audit gates read this snapshot unless `CSA_MANUSCRIPT_DIR` says otherwise.

Convention change in this version (CORRECTIONS N123): the rule-based portfolio is reported at gross exposure
one (eq. naivew, ±1/(2n) per side). The stored rule books and result CSVs stay at gross exposure 2, and every
printed rule-based level (alpha, volatility, return, factor loading) is the stored value times
`analysis.books.RULE_REPORT_SCALE`.

Every numeric token printed in these files is covered by `audit/verify_printed.py` (0 FAIL), the books-based
`audit/check_*.py` gates and the per-number ledger `audit/AUDIT_LEDGER_2026-08-29_n204.csv` (for the JFEC
render; the SSRN changes are listed in CORRECTIONS N120–N123). Figures in `figures/` are regenerated by
`figures/scripts/` and checked text-identical to these PDFs by `audit/check_figures_text.py`.
