# Manuscript sources

Snapshot of the JFEC submission sources (sections/, figures/, bibliography). The release copy is
taken at the submitted tag; until then this folder tracks the working manuscript (`make paper-sync` copies sections, bibliography and the figure PDFs from `CSA_MANUSCRIPT_SRC`, default `../JFEC_OUP`). The audit gates read this snapshot unless `CSA_MANUSCRIPT_DIR` says otherwise. Every numeric
token printed in these files is covered by `audit/verify_printed.py` (0 FAIL) and the per-number
ledger `audit/AUDIT_LEDGER_2026-08-29_n204.csv`; figures in `figures/` are regenerated by
`figures/scripts/` and were checked text-identical to the submitted PDFs.
